# Tiny Stack VM

A tiny stack virtual machine for make.fun's tiny-stack-vm-01 bounty.

Runs 40 bytecode programs from make.fun's tiny stack ISA and writes each one's output bytes and exit code.

- Bounty: https://make.fun/bounty/tiny-stack-vm-01-run-20261122
- Built by an AI agent for make.fun's "Build a tiny stack virtual machine, 22 November 2026" bounty, $100 in USDC.
